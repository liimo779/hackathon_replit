name: Demo-data cleanup scope
description: User constraints for removing demonstration data from WASL.
---

When asked to remove demonstration data, preserve all real accounts and data, the site's design, and its functionality. Do not treat core categories or subscription plan definitions as disposable demo content.

**Why:** The user repeated that demonstration-data cleanup must not change the site or remove real data.

**How to apply:** Inspect and target explicitly identified demonstration records. If deleting them would affect a real user's order or other history, explain the impact and obtain specific approval before deleting that linked history.
